# CrowPi2 Projects

A collection of Python projects and experiments made with the **CrowPi2** and Raspberry Pi.

## About

These projects explore Python programming, electronics, sensors, and the different hardware modules built into the CrowPi2.

CrowPi2 projects are essentially Raspberry Pi projects that make use of the CrowPi2's built-in hardware. Many standard Raspberry Pi projects can also be adapted to work with the CrowPi2.

**The following project** may use a Raspberry Pi with external components.

## Modules & Components

The projects may use the following CrowPi2 hardware:

* LED
* RGB LED
* Buttons
* Button Array
* Buzzer
* Relay
* Potentiometer
* Light Sensor
* Sound Sensor
* Temperature & Humidity Sensor
* Ultrasonic Distance Sensor
* PIR Motion Sensor
* IR Receiver
* IR Transmitter
* Touch Sensor
* Tilt Sensor
* Vibration Sensor
* 7-Segment Display
* 8×8 LED Matrix
* LCD Display
* Stepper Motor
* Servo Motor
* RFID/NFC Module
* Camera
